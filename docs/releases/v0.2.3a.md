**FF7Recomp for iOS 0.2.3a: pre-release.** A crash fix for save states.

> **No game is included.** You need your own Steam copy of FINAL FANTASY VII. The builder carries the engine but no game code and no game files. The IPA it makes holds the game built from your copy and your game files: **for your own devices only, never share it.** Not affiliated with or endorsed by Square Enix.

## Download

`FF7Recomp-Builder-0.2.3a.zip`: unzip it and move **FF7Recomp Builder** to Applications. Build a new FF7Recomp.ipa with it and install it over 0.2.3; your saves, save states and mods stay. (Inside, the apps report version 0.2.3, build 2: iOS version numbers can't have letters.)

## Fixed

- **A crash in battle after loading a save state made in an earlier session** (opening the app, loading a state, then a battle sound effect). A save state brought back the game's handle to its sound-effect file from the session that saved it; loading a state now reopens the game's open files. This also fixes states you saved with earlier versions.

## Known gaps

- Mods on Mega or forum pages open in Safari to download by hand; RAR archives aren't supported.
- **Quitting** closes the app; open it again to play.
- Tested on an iPhone Duo and in the simulator only.

See the [0.2.0 notes](https://github.com/eepykith/ff7-recomp-ios/releases/tag/v0.2.0) for what you need and how to use the builder. FF7Recomp for iOS is GPL-3.0.
