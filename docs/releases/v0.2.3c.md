**FF7Recomp for iOS 0.2.3c: pre-release.** A crash fix for save states.

> **No game is included.** You need your own Steam copy of FINAL FANTASY VII. The builder carries the engine but no game code and no game files. The IPA it makes holds the game built from your copy and your game files: **for your own devices only, never share it.** Not affiliated with or endorsed by Square Enix.

## Download

`FF7Recomp-Builder-0.2.3c.zip`: unzip it and move **FF7Recomp Builder** to Applications. Build a new FF7Recomp.ipa with it and install it over 0.2.3b; your saves, save states and mods stay. (Inside, the apps report version 0.2.3, build 4: iOS version numbers can't have letters.)

## Fixed

- **A crash at the next scene change after loading a save state made in an earlier session** (the screen fades to black, then the app closes). FFNx's texture conversion buffer kept its address from before the load, and after it wrote the next texture over the loaded game's memory. A save state now keeps the buffer's place, and loading one puts it back; states you saved with earlier versions load safely too.
- If the game ever frees the same memory twice, it is now noted in the engine log instead of closing the app.

## Known gaps

- Mods on Mega or forum pages open in Safari to download by hand; RAR archives aren't supported.
- **Quitting** closes the app; open it again to play.
- Tested on an iPhone Duo and in the simulator only.
